# Sign In Screen (Expo)

A clean sign-in screen built with Expo Router and React Native. The layout matches the provided design with a logo mark, title/subtitle, email and password inputs, a primary action button, and social sign-in buttons.

## Preview

- Screen implementation: [src/app/index.tsx](src/app/index.tsx)

## Run locally

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Notes

- This project uses Expo Router with file-based routing.
- The main screen lives in [src/app/index.tsx](src/app/index.tsx).
